## Overview

The **Discord Check-In/Check-Out Bot** brings structured presence tracking directly into team Discord servers. Designed for remote teams, hackathons, and virtual clubs, it provides friction-free attendance management with Discord slash commands and interactive buttons.

## Key Features

### 1. Slash Command Workflows
Members interact effortlessly using `/checkin`, `/checkout`, and `/status`. The bot records timestamps, tracks active shift duration, and notifies relevant moderators.

### 2. Timezone & Duration Calculation
Automatically computes elapsed time between check-in and check-out events, normalizing across server timezones and preventing accidental duplicate check-in loops.

### 3. Persistent Storage & Export
Logs attendance data to SQLite / database storage with exportable summaries, giving community managers actionable audit trails and weekly engagement metrics.

## Tech Stack

- **Platform:** Discord API (discord.py)
- **Runtime:** Python 3.10+ (Asyncio event loop)
- **Database:** SQLite / SQLAlchemy
- **Scheduling:** Async tasks & background worker loops
