## Overview

The **Fashion-MNIST Classifier** demonstrates an end-to-end computer vision workflow: from CNN model training and validation in PyTorch to low-latency deployment inside an interactive Streamlit web dashboard.

The application allows users to sample garments from the test dataset or upload custom images to observe how the neural network perceives patterns across 10 clothing categories (T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot).

## Model Architecture & Features

### 1. Convolutional Neural Network (CNN)
Built in PyTorch using multi-stage 2D convolutions, ReLU activations, batch normalization, max pooling, and dropout layers to prevent overfitting on the 28x28 grayscale dataset.

### 2. Streamlit Web Dashboard
Interactive UI that visualizes:
- Input image rendering alongside predicted label.
- Top-k softmax probability bar charts.
- Confusion matrix and validation accuracy metrics.

### 3. Real-Time Inference Pipeline
Optimized tensor transformations that automatically resize, grayscale-convert, and normalize inputs to match the model's trained distribution.
